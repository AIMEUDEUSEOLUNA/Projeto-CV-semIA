# Currículo - João Pedro Guerrero Luna

Este projeto apresenta meu currículo pessoal desenvolvido utilizando HTML e CSS.

## Sobre o projeto

O objetivo deste projeto foi desenvolver uma página pessoal apresentando minhas informações acadêmicas, profissionais, habilidades, projetos e formas de contato.

Esta versão foi desenvolvida **sem o uso de Inteligência Artificial**, como parte da atividade proposta durante os estudos de HTML e CSS.

## Tecnologias utilizadas

* HTML5
* CSS3

## Informações apresentadas

* Sobre mim
* Formação acadêmica
* Experiência profissional
* Projetos
* Habilidades
* Cursos
* Contato
